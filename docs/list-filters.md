# 简历与股票筛选

2026-10-29，本轮在原生 Flutter 主应用中加入组合筛选，不改变已有投递、岗位、报价或自选数据，也不新增数据库迁移。

投递记录保留原有进展标签和搜索，并增加“筛选”面板，可同时按投递进展、公司、岗位、渠道及投递开始/结束日期过滤。日期区间包含两端；未填日期或无效日期的记录在未启用日期限制时仍保留，启用日期限制后不匹配。日期倒置会阻止应用条件。

岗位与匹配增加行业、职能、工作地点、学历要求、单位类型和简历关键词匹配条件。多工作地点岗位只要包含所选地点就会保留。结果继续按原有关键词命中数量排序，并与搜索条件叠加。匹配依据现有简历与目录中的关键词，不代表满足全部招聘条件；没有要求关键词的条目不会被自动判为全部命中。

股票跨市场目录保留原市场快捷标签，增加市场、行业、风险、自选状态、行情状态、涨跌和价格区间筛选。我的自选也支持市场、行业、风险、分组、行情状态、涨跌及价格筛选，并兼容旧版分组关联键和未分组记录。筛选本身不触发网络行情请求，使用已经读取或云端保存的报价；来源与获取时间继续展示。价格按标的原币，不做汇率换算。没有有效价格的条目不会被当作零价；缺失涨跌值不会被当作平盘。

所有条件按“同时满足”组合；选项来自完整可用数据，不会在筛选后自行缩小选项范围。面板内的修改需要点击“应用筛选”才生效，取消保持原条件，“清空筛选”移除条件并保留搜索文本。若服务器刷新使某个已选值暂时没有记录，仍保留该条件并显示“当前无记录”，不会悄悄扩大查询范围。筛选状态只保留于当前页面会话，不作为业务数据写回服务器。

手机与桌面共用可滚动的筛选面板；新入口旁及列表中显示过滤后的数量。六张新面板布局截图位于 outputs/filters-20261029/ui/。
