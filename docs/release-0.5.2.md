# WorkSpace 0.5.2

新增“关于与更新”：已安装用户可以主动检查后续版本、查看更新内容，并下载对应的 Windows 完整包或 Android APK。登录页也保留入口。版本清单独立发布，今后发布新包后更新清单即可让旧客户端查到更新。

登录用户下载更新前先确认云端同步，创建本机加密备份，并通过回读校验后再打开下载地址。保存或专注记录尚未完成、备份失败时暂停下载；可导出更新备份，之后通过“数据与恢复”导入。备份按账号和云项目隔离，保留原记录标识、正文、关联字段、日期和回收站信息。更新流程不清空账号数据。

发布时核对 Android 应用 ID、签名、Windows 数据目录标识和云项目指纹。客户端拒绝不兼容的版本清单，安全存储操作采用排队和 Windows 文件锁，避免备份密钥写入与会话刷新互相覆盖。

Windows 关闭旧程序后解压完整新包使用，Android 使用同签名 APK 覆盖安装。0.5.1 用户需先手动安装一次 0.5.2，建议先通过“数据与恢复”导出备份；以后使用应用内更新入口。

这是公开测试版。已进行静态检查、版本协议、下载分流、异常重试、业务集合加密备份回读及界面回归测试；Android 真机覆盖安装和双设备同步仍待实测。请保留独立备份。
