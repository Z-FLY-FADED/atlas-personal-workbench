# WorkSpace 0.6.0

2026-10-29 · 构建号 10 · 公开测试版

本版将个人来源采集、组合筛选和个人 AI API 接入 Windows / Android 主应用。

投递记录支持进展、公司、岗位、渠道和日期筛选；岗位与匹配支持行业、职能、地点、学历、单位类型与关键词命中条件。股票目录及自选支持市场、行业、风险、行情、涨跌、价格与分组等组合条件，缺失行情不会被当作零价或平盘。

行业速览关注 AI、机器人、智能制造、新能源，区分科技公众号、大厂公众号、新闻频道、科技媒体和官网新闻。支持原始发布时间排序、方向和近期筛选，可添加推荐来源、查看采集记录，并将资料收录到个人知识库。采集需主动点击“更新来源”，没有后台定时任务。

微信支持单篇公开正文提取和用户已授权订阅源接入。单篇模式不能发现新推文；实测微信返回验证页，当前未接通公众号最新推文的持续采集。新闻源实测 IT之家、央视科技、NVIDIA 成功，36氪本次超时。BOSS 具体岗位入口曾采集成功，智联及部分公告站仍受公开页面、超时或证书问题限制，需核对原文与实际招聘状态。

AI 助手可添加多组兼容 Chat Completions 的 API 与模型，检索当前账号知识和资料、总结或生成正文修改建议。修改先预览，再经版本校验确认保存。密钥在服务端加密保存，AI 默认关闭；真实模型生成需使用者添加自己的有效 API，本轮未调用付费模型验证。

现有账号、业务数据、Android 应用 ID 与长期签名、Windows 产品标识保持兼容。0.5.2 用户在“关于与更新”检查新版，下载前先同步并创建本机加密备份。Windows 关闭旧程序后解压完整 ZIP 使用；Android 使用同签名 APK 覆盖安装。

修复较宽字体下侧栏品牌文字的溢出，适配不同设备的文字尺寸。项目首页新增中英文介绍、演示截图和反馈模板。

发布检查包含 Flutter 静态分析、157 项客户端回归通过（1 项可选迁移测试跳过）、13 项服务器测试、云端账号隔离与 RLS 回滚检查、原有数据摘要校验、双平台构建及 APK 签名核对。Windows 未做商业代码签名；Android 真机覆盖安装与双设备同步仍待实测。
