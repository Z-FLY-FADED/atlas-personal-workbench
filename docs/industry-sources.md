# 行业速览来源与采集

本页围绕 AI、机器人、智能制造、新能源聚合三类核心来源：科技公众号、大厂公众号、新闻频道。科技媒体与大厂官网新闻作为额外来源，明确单独标注，不冒充公众号。

## 公众号内容

添加来源时可先选择机器之心、量子位、极客公园、华为、腾讯、小米等账号名称模板，再选择采集方式。模板仅填账号名称与类别，不代表已经接通该账号或验证其官方身份。

“微信单篇正文直采”接收 mp.weixin.qq.com/s 链接，读取公开页面中的标题、发布账号、真实发布时间和正文，清理脚本后保存；不会执行页面脚本。单篇模式不会自动发现新推文。微信要求验证或未返回正文时，记录失败，不把验证页当作文章。

“RSS / Atom / 自建 RSSHub”接收经用户登录授权的公众号订阅服务生成的 RSS、Atom 或 JSON Feed，可按源更新推文。服务端要求公众号订阅的原文链接确实来自微信域名，官网 RSS 不能标为公众号。单篇微信 URL 不能按持续订阅保存。

本轮用从 36氪公开页面获取的真实微信文章链接进行了云端测试，微信返回“环境异常，完成验证后继续访问”，没有获得正文。公开检索里还出现多年旧文章，不能当作最新推文；检索站对自动采集也有限制，因此这里只提供“打开公众号公开检索”的手动核对入口，没有绕过验证或解码受保护跳转。

持续获取公众号最新推文需要用户授权登录的公众号采集服务。例如 [WeWe RSS](https://github.com/cooderl/wewe-rss) 的官方说明要求在账号管理中扫码登录微信读书，再添加公众号，随后生成订阅源。当前没有用户提供的已授权公众号订阅源，本轮未部署带真实微信会话的采集服务，也不能声明公众号自动更新已经接通。不要把微信 Cookie、扫码登录令牌或验证码发到聊天中；这些应留在用户自己控制的采集服务里。

## 可直接使用的新闻来源

页面增加“添加推荐新闻源”，将以下公开来源及四个关注方向保存到当前账号。相同来源不会重复添加，也不会改动其他账号配置：

- IT之家 RSS：科技媒体。
- 36氪 RSS：科技媒体。
- 央视网科技公开栏目数据：新闻频道。
- NVIDIA 官方博客 RSS：大厂官网新闻。

每个来源可以单独启停、设置关注方向和关键词。清空关注方向时收录该来源全部内容。按关注方向分类使用关键词规则，不调用 AI。点击“更新来源”才采集，保留五分钟来源冷却机制；本轮未配置后台定时任务。

## 最新与时间

列表按原始发布时间从新到旧排列，兼容已有 ISO 与 RSS HTTP 日期。未知发布时间放在末尾，不能因刚采集就排成最新；近 24 小时、近 7 天、近 30 天筛选会排除未知发布时间条目。来源类别与行业方向均可叠加过滤。每条显示发布机构、发布时间、采集时间与原文链接。

正文或正文摘录可沉淀到当前账号知识库。所有来源、文章及采集运行仍走原有 repository / RPC / RLS，不修改其他账号内容，不将模型密钥嵌入客户端。
